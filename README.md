# Biblioteca de Prompts para IA´s

Biblioteca personal de prompts organizada por modelo de IA y categoría.

- `index.html`: aplicación web autónoma (sin conexión, sin cuentas). Ábrela en el navegador.
- `<Modelo>/<categoría>/*.md`: cada prompt es un archivo Markdown con front matter (titulo, modelo, categoria, etiquetas, fecha, valoracion, version) y secciones Prompt, Ejemplo de resultado y Notas.

Las partes variables van entre [CORCHETES]. Desde la web puedes importar la carpeta entera o añadir prompts nuevos.
