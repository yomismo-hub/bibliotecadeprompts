## Prompt

Use [IMAGE 1] only for [ROLE: character identity]. Use [VIDEO 1] only for [ROLE: camera movement]. Timeline: 0-[N]s [EVENT A]; [N]-[M]s [EVENT B]. Sound: [SOUND] when [VISIBLE ACTION]. End on [FINAL FRAME].

## Ejemplo de resultado

Pega aquí un resultado real o un resumen de lo que devolvió.

## Notas

- Da a cada referencia un único rol; roles contradictorios confunden al modelo.
- Usa rangos de segundos solo si varios eventos deben caber en un mismo clip.
- Vincula el sonido a acciones visibles y define el último encuadre si importa para el montaje.
